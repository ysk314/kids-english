# 幼児英語アプリ 要件定義 v1.0（引き継ぎ版）

最終更新: 2026-02-09

## 1. 目的
- 幼児英語授業を、講師タブレット操作と大画面ミラー表示で一貫運用する。
- 授業の流れをテンプレート化し、講師ごとの差を減らす。
- まずは第5週（反対語ユニット）を実授業できる品質で完成させる。

## 2. スコープ
### 2.1 MVP必須画面
- ダッシュボード
- カリキュラムマップ
- 授業ランナー（講師用）
- 大画面表示（児童用）
- カードスタジオ
- 教室設定

### 2.2 初期リリース対象外
- 進捗トラッカー
- 毎週ミッション関連UI
- 対戦クイズ専用画面

## 3. 対象環境
- 講師端末: iPad Safari（推奨）
- 児童表示: 教室大画面（ミラーリング）
- 実装形態: Webアプリ（インストール不要）

## 4. 授業運用ルール（確定）
- 進行は `1問ごとに次へ/前へ` の固定。
- タイマーは `全体45分` のみ。
- 加点タイミングは講師裁量（授業中いつでも）。
- 導入語彙は `4セット固定`。
- 英語導入は英語本題の前に実施。

## 5. 講師コントローラー（授業ランナー）
必須操作:
- 大画面をひらく
- サウンド/BGM ON-OFF
- 正解
- 不正解
- みんなに+1
- むつみ先生+1
- 点数リセット
- 前へ
- 次へ

追加ルール:
- `←` / `→` キーで前後移動可能。
- 正解/不正解ボタンは派手なクイズ音を再生。

## 6. 大画面表示ルール（児童向け）
- 出す: 問題、カード、選択肢、授業進行に必要な最小説明。
- 出さない: 児童名、評価UI、講師操作UI、講師ヒント。
- 日本語パート: ひらがな中心（児童可読性優先）。
- 英語パート: 英語のみ。
- ポイント表示: ヘッダー内に `みんな / むつみ先生` を表示。
- 大画面内の `おんがくあり / BGM ON` 表示は出さない。
- 演出:
  - 加点時エフェクト（みんな+1 / むつみせんせい+1）
  - 正解エフェクト: `◯`
  - 不正解エフェクト: `×`
  - End時: 得点発表 + 花吹雪風演出 + 効果音

## 7. 導入（リズム）仕様
- 日本語導入: BPM 90
- 英語導入: BPM 95
- 動作ルール: 同じ動作で速度のみ変更
- 音: BGM + ドラム系リズム（ハイハット/スネア/キック）

第5週固定4セット:
- ながい / みじかい
- きれい / きたない
- あかるい / くらい
- たつ / すわる

英語パート画像:
- 英語文字が画像内で重複しないよう、英語パートも日本語パートと同じカード画像を使用し、表示テキストのみ英語にする。

## 8. 第5週フロー要件
- スライド総数: 49枚
- 構成:
  - テーマタイトル
  - 日本語導入4枚 + まとめ + 区切り
  - 日本語ワーク8問
- 日本語深掘り（順次比較4 + 比較切替4）
  - 順次比較は1枚ずつ表示（みじかいえんぴつ→ながいえんぴつ→へび→でんしゃ）
  - 英語導入開始スライド
  - 英語導入4枚 + まとめ + 区切り
  - 英語ワーク8問
  - 英語深掘り（順次比較4 + 比較切替4）
  - Endスライド

## 9. 音仕様（確定）
- 正解音: `mockup/assets/audio/correct.mp3`
- 不正解音: `mockup/assets/audio/wrong.mp3`
- 合成フォールバック音は使わない運用。

## 10. 受け入れ基準
- 授業ランナーから49枚を止まらずに進行できる。
- 大画面と授業ランナー内プレビューが同じ表示を出す。
- 加点/正誤エフェクトが大画面とプレビュー両方で表示される。
- 日本語/英語の表示言語ルールが崩れない。
- GitHub Pages上でもデザイン崩れなく動作する。

## 11. デプロイ要件
- GitHub Pagesを利用。
- `main` pushでGitHub Actionsが自動デプロイ。
- Pages URL配下でも動くよう、公開ビルドは相対パス解決を使用。
