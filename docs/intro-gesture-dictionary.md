# 導入アクティビティ辞書（授業運用版）

最終更新: 2026-02-09

## 1. パート別テンポ
- 日本語導入: BPM 90（余韻 0.3〜0.4秒）
- 英語導入: BPM 95（余韻 0.2〜0.3秒）
- 原則: 動作は同じ、スピードのみ変更

## 2. 第5週 固定4セット
- ながい / みじかい
- きれい / きたない
- あかるい / くらい
- たつ / すわる

## 3. 共通ルール
- 1語 = 1動作（固定）
- 対語は対の動きで揃える
- 発話は短く区切る
- 音に合わせて全員で声を揃える

## 4. ジェスチャー辞書
### 4.1 はんたい・くらべる
- 大きい / Big: 両手を大きく広げる
- 小さい / Small: つまむ
- 長い / Long: 横に引っ張る
- 短い / Short: 少しだけ開く
- 明るい / Bright: ぱっと開く
- 暗い / Dark: 目を覆う
- 速い / Fast: シャカシャカ
- おそい / Slow: スローモーション

### 4.2 まとめる・くわしく
- まとめて / All together: 外→内へ寄せる
- グループ / Group: 丸で囲う
- 同じ / Same: 指を並べる
- ちがう / Different: 指を開いて分ける
- たとえば / For example: 1つ摘んで前へ

### 4.3 どんなだ・なんだ
- みる / Look: 目→対象
- いろ / Color: 塗る動作
- かたち / Shape: 輪郭をなぞる
- 〜じゃない / Not: 腕で×

### 4.4 どうする（動詞）
- jump / run / walk / sit / stand / sleep
- eat / drink / read / write
- open / close / give / take / throw / catch

### 4.5 接続・因果
- だから / So: 前へ一歩
- しかし / But: 横へ/方向転換
- なぜなら / Because: 後ろを指して前へ

### 4.6 要約・例示
- たとえば / For example: 1つ前へ
- つまり / In short: 外→内でまとめる

### 4.7 こそあど
- これ / This: 自分の前
- それ / That: 相手の前
- あれ / That over there: 遠く
- どれ / Which: 左右交互

### 4.8 助動詞
- can: 力こぶ
- can't: 力こぶ→×
- want to: 胸にハート
- don't want to: ハート→×
- will: 前を見る・前を指す

### 4.9 ならびかえ
- First / Next / Then / Last
- OK: ○
- NG: ×

- 日本語パートはひらがな中心。
- 詳細な説明文は授業ランナーの講師ヒント側に置く。
