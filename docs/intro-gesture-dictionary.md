# 導入アクティビティ仕様（身体を動かす・リズミカルな意味提示）

## 1. パート別テンポ
- 日本語導入
  - BPM: 90
  - 余韻: 0.3〜0.4秒
  - ねらい: 子どもの声出しを促す
- 英語導入
  - BPM: 95
  - 余韻: 0.2〜0.3秒
  - ねらい: 英語モードへの切り替え感を出す

## 1.1 第5週で使う固定セット
- 4セット固定で運用（導入の語彙数を毎回一定化）
  - 長い / 短い
  - きれい / よごれ
  - 明るい / 暗い
  - 立つ / 座る
- 導入音は `メトロノーム + BGM` を併用する

## 2. 共通ルール
- 1語 = 1動作（固定）
- 対語は対になる動きで固定
- 抽象語は「囲う/まとめる/上に置く」で表現
- 否定・比較・因果は方向で表現
- 発話は短く（日本語2〜3音、英語1語）

## 3. ジェスチャー辞書
## 3.1 はんたい・くらべる
### サイズ・量
- 大きい / Big: 両手を大きく横に広げる
- 小さい / Small: 両手をつまむ
- たくさん / Many: 両手指をパッと開く
- すこし / A little: 指でちょびっと
- 重い / Heavy: 両手で持ち上げて沈む
- 軽い / Light: 片手でふわっと持ち上げる

### 長さ・高さ・幅
- 長い / Long: 両手を横へ引っ張る
- 短い / Short: 両手を少しだけ開く
- 高い / High: 片手を頭上へ
- 低い / Low: 片手を腰位置へ
- 広い / Wide: 両腕を左右へ
- せまい / Narrow: 肘を体へ寄せる

### 速さ・温度・明暗
- 速い / Fast: 手をシャカシャカ（足踏み可）
- おそい / Slow: スローモーション
- あつい / Hot: 手をパタパタ
- つめたい / Cold: 肩をすくめてブルブル
- 明るい / Bright: いないいない→パッ
- 暗い / Dark: 両手で目を覆う

### 形・質感
- かたい / Hard: 拳を作ってカチカチ
- やわらかい / Soft: 手のひらをほっぺに当てる
- なめらか / Smooth: 前腕をスーッとなでる
- ざらざら / Rough: 指先でこする

## 3.2 まとめる・くわしく
### 集める・まとめる
- まとめて / All together: 両手を外→内へ寄せる
- グループ / Group: 両手で丸を作って囲う
- 同じ / Same: 人差し指を並べてピタッ
- ちがう / Different: 人差し指を左右に開く

### 上（抽象）/ 下（具体）
- 〜のなかま / family of ...: 手で輪っか
- 上（大カテゴリ） / Category: 手を上に置く
- 下（具体） / Example: 下に置く
- たとえば / For example: 1つつまんで前へ

### くわしく
- どこ？ / Where?: キョロキョロ+指差し
- なに？ / What?: 両手を軽く開く
- どれ？ / Which?: 左右交互に指差し
- なぜ？ / Why?: こめかみに指

## 3.3 どんなだ・なんだ
- みる / Look: 目→対象
- かたち / Shape: 空中で輪郭
- いろ / Color: 塗る動作
- おおきさ / Size: 両手で幅
- きらきら / Shiny: 指をキラキラ
- まるい / Round: 両手で丸
- しかくい / Square: 空中で四角
- 〜じゃない / Not ...: 腕で大きな×

## 3.4 どうする（動詞）
- jump / run / walk / sit / stand / sleep
- eat / drink / read / write / open / close
- give / take / throw / catch
- happy / sad / angry / scared

※ 動作は語義どおりの身体動作に固定。

## 3.5 接続語・因果
- だから / So: 前へ一歩
- しかし / But: 方向転換 or 横スライド
- それで / Then: トントントンと前進
- なぜなら / Because: 後ろを指してから前へ

## 3.6 要約・例示
- たとえば / For example: 1つ摘まんで前へ
- つまり / In short: 両手を外→内にまとめる
- まとめる / Summarize: 上から蓋を閉じる

## 3.7 こそあど
- これ / This: 自分の前
- それ / That: 相手の前
- あれ / That over there: 遠く
- どれ / Which: 左右交互 + キョロキョロ

## 3.8 形を変える（助動詞）
- can: 力こぶ
- can't: 力こぶ→×
- want to: ハートを胸に
- don't want to: ハート→×
- will: 前を見る + 前を指す

## 3.9 ならびかえ
- First: 指1本
- Next: 指2本
- Then: 指3本
- Last: 拍手1回
- OK / Correct: ○
- NG / Wrong: ×

## 4. UI要件への反映
- 授業ランナーに「導入開始（JP/EN）」ボタンを設置
- 導入中は、語・ジェスチャー名・カウントを大きく表示
- 大画面は見本動作を示す短文と語だけを表示
- 日本語導入から英語導入へ切り替える際は、同じ語群でBPMのみ変更
