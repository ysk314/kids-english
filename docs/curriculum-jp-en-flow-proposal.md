# 39週カリキュラム 日本語/英語 授業フロー提案（表側）

## 共通フォーマット（45分）
- 導入 5分: 前回復習と今日のルール確認
- 日本語パート 15分: 概念理解（日本語のみ表示）
- 英語パート 15分: 同内容を英語化（英語のみ表示）
- スペシャル 8分: ミニ発表/対戦演出（4週目は専用なりきり）
- ふりかえり 2分: 勝敗発表と次回予告

### パート内ミニ導入（毎回実施）
- 日本語パート冒頭 90秒: リズミカル導入（BPM 90 / 余韻0.3〜0.4秒）
- 英語パート冒頭 90秒: 同一動作で速度のみ+5（BPM 95 / 余韻0.2〜0.3秒）
- 導入語彙は、その週の活動語彙に合わせて3〜6語を選ぶ

## 表示テンプレートの使い分け（UI設計指針）

- ペア: W5, W7
- 階層/並び替え: W2, W3, W22, W37, W38, W39
- ジェスチャー/移動: W13, W29-31

## UI上の重要ポイント
- 「4枚選択」だけに固定しない。週テンプレートでレイアウトを切り替える。
- 日本語/英語パートは大画面言語を完全分離する。
- どのテンプレートでも、講師操作は `前へ / 次へ / 生徒+1 / 講師+1` の4操作を維持する。
- 導入アクティビティは、同じ動作でBPMだけ変更して日本語/英語パートを接続する。

※ 導入語彙と動作の定義は `docs/intro-gesture-dictionary.md` を正とする。
