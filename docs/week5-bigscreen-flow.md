# 第5週 大画面フロー（43枚・確定）

最終更新: 2026-02-09

## 1. 全体構成
- 合計: 43枚
- 日本語と英語で同じ学習構造を採用し、言語だけ切り替える。

## 2. スライドブロック
1. `11_theme_title`（1枚）
- 今日のテーマを提示

2. 日本語導入（6枚）
- `12_jp_rhythm_1`〜`12_jp_rhythm_4`（4枚）
- `12_jp_rhythm_summary`（1枚）
- `12_jp_break_work`（1枚）

3. 日本語本題（8枚）
- `13_jp_work_1`〜`13_jp_work_8`
- 形式: 大カード1枚 + 候補2枚

4. 日本語深掘り（6枚）
- `13_jp_break_deep`（1枚）
- `14_jp_deep_step_1`〜`14_jp_deep_step_4`（4枚）
- `15_jp_deep_compare_1`（1枚）
- `15_jp_deep_compare_1` は `スライド内進行` で比較ペアを4段階切替

5. 英語開始（1枚）
- `15_break_en_start`

6. 英語導入（6枚）
- `16_en_rhythm_1`〜`16_en_rhythm_4`（4枚）

- `16_en_break_work`（1枚）

7. 英語本題（8枚）
- `17_en_work_1`〜`17_en_work_8`
- 形式: 大カード1枚 + 候補2枚

8. 英語深掘り（6枚）
- `17_en_break_deep`（1枚）
- `18_en_deep_step_1`〜`18_en_deep_step_4`（4枚）
- `19_en_deep_compare_1`（1枚）
- `19_en_deep_compare_1` は `スライド内進行` で比較ペアを4段階切替

9. 終了（1枚）
- `20_end`

## 3. 表示ルール
- 日本語パート: 児童向け表示はひらがな中心。
- 英語パート: 英語のみ表示。
- 英語スライド画像: 画像内英語の重複を避けるため、日本語パートと同じカード画像を使用し、テキストのみ英語表示。
- ワーク画面:
  - 正答ハイライトは表示しない。
  - 見出しは短く、下余白を抑えてカードを大きく見せる。
- 深掘り画面:
  - `deep_step` は1枚ずつ表示（1: みじかいえんぴつ / 2: ながいえんぴつ / 3: へび / 4: でんしゃ）。
- `deep_compare` は赤枠ペアのみ切り替え。
- `rhythm_summary` の進捗バーは4本（導入4セットと一致）。
- 大画面には `おんがくあり / BGM ON` チップを表示しない。

## 4. 進行・演出ルール
- 進行単位: 1問ごと。
- 導入テンポ:
  - 日本語 BPM90
  - 英語 BPM95
- `deep_compare` でもテンポ維持のためドラムを継続（日本語90 / 英語95）。
- 音:
  - BGMはON/OFF可能
  - 正解/不正解は専用音源
- エフェクト:
  - 加点時: みんな/むつみせんせいの演出
  - 正解: `◯`
  - 不正解: `×`
  - End: 得点発表 + 花吹雪風演出 + 効果音

## 5. 連携
- 授業ランナーの選択スライドが大画面へミラー同期される。
- 授業ランナー内の大画面プレビューにも同じ演出を表示する。
- 操作用語:
  - `前へ / 次へ`: スライド移動
  - `◀ スライド内 / スライド内 ▶`: スライド内進行
  - Endの `スライド内 ▶`: 結果発表トリガー（表示はシンバル音タイミング）
